# Source lock

No external data is bundled or required: the finite controls are constructed
from scratch. The theorems import the following, cited in the paper and owned by
their authors.

| input | owner |
|---|---|
| higher-star diagonal form of `t`-vs-`k` subset incidence | R. M. Wilson, *European J. Combin.* 11 (1990) 609–615 |
| universal additive/incidence group; `t=2` case | Caggegi–Falcone–Pavone, *J. Algebraic Combin.* 45 (2017) 271–294 |
| invariant factors of `PG(n,q)`/`AG(n,q)` incidence | Chandler–Sin–Xiang, *TAMS* 358 (2006) 4935–4957 |
| Miquelian / even-order Moebius incidence Smith forms | Ringe, dissertation (2008) |
| finite symmetric bilinear forms | C. T. C. Wall, *Topology* 2 (1963) 281–298 |
| discriminant-form / overlattice framework | Nikulin, *Math. USSR-Izv.* 14 (1980) 103–167 |
| exact `S(2,5,v)` existence | Hanani, *JCTA* 12 (1972) 184–201 |
| Hermitian unital incidence divisors | Hiss, *Indag. Math.* (2004) |
| order-16 Hadamard / `STS(15)` binary ranks | Assmus–Key, *TAMS* 330 (1992) 269–293 |
| `STS(15)` code/affine-lattice classification | Solé (1997) |
| prescribed-rank Steiner carriers / counts | Jungnickel–Tonchev; Keevash-type |
